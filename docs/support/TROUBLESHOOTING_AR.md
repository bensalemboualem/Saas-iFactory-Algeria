## 1. مشاكل الاتصال

### 1.1 تعذر تسجيل الدخول

**الأعراض:**
- صفحة تسجيل الدخول تعيد التحميل بشكل متكرر
- رسالة "بيانات الاعتماد غير صحيحة"
- شاشة بيضاء بعد تسجيل الدخول

**الحلول:**

1. **تحقق من بيانات الاعتماد**
   ```
   - تحقق من صحة البريد الإلكتروني (انتبه للمسافات)
   - كلمة المرور حساسة لحالة الأحرف
   ```

2. **امسح ذاكرة التخزين المؤقت للمتصفح**
   ```
   Chrome: Ctrl+Shift+Delete > كل الوقت > مسح
   Firefox: Ctrl+Shift+Delete > كل شيء > مسح
   Safari: Cmd+Alt+E
   ```

3. **عطّل الإضافات**
   - مانعات الإعلانات قد تمنع الطلبات
   - VPN/Proxy قد تسبب مشاكل

4. **جرب وضع التصفح الخاص**
   ```
   Chrome: Ctrl+Shift+N
   Firefox: Ctrl+Shift+P
   ```

5. **أعد تعيين كلمة المرور**
   - [رابط إعادة تعيين كلمة المرور](https://app.iafactory.ai/forgot-password)

### 1.2 انتهاء الجلسة بشكل متكرر

**السبب المحتمل:** ملفات تعريف الارتباط محظورة أو تُحذف تلقائياً

**الحل:**
1. اسمح بملفات تعريف الارتباط لـ `*.iafactory.ai`
2. تحقق من أن المتصفح لا يحذف ملفات تعريف الارتباط عند الإغلاق
3. عطّل إضافات التنظيف التلقائي

### 1.3 خطأ "محاولات كثيرة جداً"

**الحل:**
- انتظر 15 دقيقة
- استخدم "نسيت كلمة المرور" إذا لزم الأمر
- اتصل بالدعم إذا استمرت المشكلة

## 2. مشاكل الأداء

### 2.1 واجهة بطيئة

**التشخيص:**

```javascript
// افتح وحدة التحكم (F12) ونفذ:
performance.now()
// ثم بعد التنقل:
performance.now()
// الفرق > 3000ms = مشكلة
```

**الحلول:**

1. **تحقق من اتصال الإنترنت**
   ```bash
   # اختبار زمن الاستجابة
   ping api.iafactory.ai
   ```

2. **قلل المحادثات النشطة**
   - أرشف المحادثات القديمة
   - حدد إلى 20 محادثة مرئية

3. **حدّث المتصفح**
   - Chrome، Firefox، Safari أحدث إصدار

4. **عطّل الرسوم المتحركة (إمكانية الوصول)**
   ```
   الإعدادات > إمكانية الوصول > تقليل الرسوم المتحركة
   ```

### 2.2 تحميل الرسائل بطيء

**الأسباب المحتملة:**
- محادثة بها رسائل كثيرة (>100)
- رسائل بصور/ملفات كبيرة

**الحلول:**
1. أنشئ محادثة جديدة
2. صدّر وأرشف القديمة
3. فعّل "التحميل التدريجي" في الإعدادات

### 2.3 استخدام ذاكرة عالي

**العرض:** المتصفح يستهلك > 2GB من RAM

**الحلول:**
1. أغلق علامات التبويب غير الضرورية
2. أعد تحميل الصفحة (F5)
3. استخدم تطبيق سطح المكتب (أكثر تحسيناً)

## 3. أخطاء الذكاء الاصطناعي

### 3.1 "خطأ في التوليد"

**الرمز: `AI_GENERATION_ERROR`**

**الأسباب والحلول:**

| السبب | الحل |
|-------|------|
| خادم الذكاء الاصطناعي مثقل | أعد المحاولة بعد دقيقة |
| الطلب طويل جداً | قلل إلى < 4000 توكن |
| محتوى مفلتر | أعد الصياغة بدون مصطلحات حساسة |
| انتهاء المهلة | قسّم الطلب إلى أجزاء |

### 3.2 "النموذج غير متاح"

**الرمز: `MODEL_UNAVAILABLE`**

**الحلول:**
1. تحقق من الحالة: [status.iafactory.ai](https://status.iafactory.ai)
2. جرب نموذجاً آخر
3. انتظر الصيانة (عادة < 1 ساعة)

### 3.3 استجابة مقطوعة

**العرض:** الاستجابة تتوقف فجأة

**الأسباب:**
- تم الوصول لحد التوكنات
- انتهاء مهلة التوليد

**الحلول:**
1. اطلب "تابع" أو "استمر"
2. زد حد التوكنات (الإعدادات > النموذج)
3. اطلب استجابة أقصر

### 3.4 استجابة غير صحيحة / هلوسات

**الذكاء الاصطناعي قد يحياناً:**
- يخترع حقائق
- يعطي معلومات قديمة
- يناقض نفسه

**أفضل الممارسات:**
1. تحقق دائماً من المعلومات المهمة
2. اطلب المصادر
3. أعد الصياغة مع مزيد من السياق
4. استخدم نموذجاً أحدث (GPT-4، Claude 3)

## 4. مشاكل الدفع

### 4.1 الدفع مرفوض

**Chargily Pay (الجزائر):**

| الخطأ | الحل |
|-------|------|
| البطاقة غير معروفة | تحقق من تفعيل CIB/الذهبية للتجارة الإلكترونية |
| رصيد غير كافٍ | تحقق من رصيد البنك |
| الحد مُستنفد | اتصل ببنكك |
| رمز OTP غير صالح | اطلب رمزاً جديداً |

**البطاقة الدولية:**

| الخطأ | الحل |
|-------|------|
| فشل 3D Secure | اسمح بالمعاملات عبر الإنترنت |
| بطاقة منتهية | حدّث معلومات البطاقة |
| عنوان غير صالح | استخدم عنوان الفوترة الدقيق |

### 4.2 الاشتراك لم يُفعّل

**بعد دفع ناجح ولكن بدون أرصدة:**

1. انتظر 5 دقائق (المزامنة)
2. تسجيل الخروج/الدخول
3. تحقق في الإعدادات > الفوترة
4. اتصل بالدعم مع إيصال الدفع

### 4.3 خطأ في الفوترة

**الإجراء:**
1. حمّل الفاتورة المعنية
2. أرسل إلى billing@iafactory.ai مع:
   - رقم الفاتورة
   - وصف المشكلة
   - المبلغ المتوقع مقابل المفوتر
3. وقت المعالجة: 5 أيام عمل

## 5. مشاكل API

### 5.1 خطأ 401 Unauthorized

```json
{
  "error": "unauthorized",
  "message": "Invalid API key"
}
```

**الحلول:**
1. تحقق من صحة مفتاح API
2. تحقق من عدم إلغائه
3. أنشئ مفتاحاً جديداً إذا لزم الأمر

### 5.2 خطأ 429 Too Many Requests

```json
{
  "error": "rate_limited",
  "message": "Too many requests",
  "retry_after": 60
}
```

**الحلول:**
1. نفذ تراجع أسي
2. احترم حدود باقتك
3. قم بالترقية إذا كنت بحاجة لمزيد من الطلبات

**الحدود حسب الباقة:**

| الباقة | الطلبات/دقيقة |
|--------|---------------|
| مجاني | 10 |
| برو | 60 |
| برو+ | 300 |
| المؤسسات | مخصص |

### 5.3 خطأ 500 Internal Server Error

```json
{
  "error": "internal_error",
  "message": "Something went wrong",
  "request_id": "req_abc123"
}
```

**الإجراءات:**
1. أعد محاولة الطلب
2. تحقق من status.iafactory.ai
3. إذا استمر، اتصل بالدعم مع `request_id`

### 5.4 انتهاء المهلة

**العرض:** الطلب لا يكتمل

**الحلول:**
1. زد مهلة العميل (موصى به: 120 ثانية للتوليد)
2. استخدم البث للاستجابات الطويلة
3. قسّم الطلبات الكبيرة

## 6. مشاكل الجوال/سطح المكتب

### 6.1 تطبيق سطح المكتب - شاشة بيضاء

**Windows:**
```bash
# احذف ذاكرة التخزين المؤقت
rmdir /s /q "%APPDATA%\iafactory"
# أعد تشغيل التطبيق
```

**macOS:**
```bash
rm -rf ~/Library/Application\ Support/iafactory
rm -rf ~/Library/Caches/iafactory
```

**Linux:**
```bash
rm -rf ~/.config/iafactory
rm -rf ~/.cache/iafactory
```

### 6.2 تطبيق سطح المكتب - لا يبدأ

**الحلول:**
1. تحقق من متطلبات النظام
   - Windows 10+ / macOS 10.15+ / Ubuntu 20.04+
   - 4GB RAM كحد أدنى
2. شغّل كمسؤول (Windows)
3. أعد تثبيت التطبيق

### 6.3 المزامنة بين الأجهزة

**العرض:** محادثات مختلفة على الويب وسطح المكتب

**الحلول:**
1. تحقق من اتصال الإنترنت على كلا الجهازين
2. أجبر المزامنة: الإعدادات > البيانات > مزامنة
3. تسجيل الخروج/الدخول

## 7. رموز الأخطاء

### مرجع سريع

| الرمز | الوصف | الحل السريع |
|-------|-------|-------------|
| `AUTH_001` | انتهاء صلاحية الرمز | أعد الاتصال |
| `AUTH_002` | الحساب معطّل | اتصل بالدعم |
| `AUTH_003` | 2FA مطلوب | أدخل رمز 2FA |
| `CRED_001` | أرصدة غير كافية | اشترِ أرصدة |
| `CRED_002` | الحد اليومي | انتظر 24 ساعة أو قم بالترقية |
| `AI_001` | النموذج غير متاح | جرب نموذجاً آخر |
| `AI_002` | الطلب طويل جداً | قصّر الطلب |
| `AI_003` | المحتوى مفلتر | أعد صياغة الطلب |
| `AI_004` | انتهاء مهلة التوليد | أعد المحاولة أو قسّم |
| `API_001` | مفتاح غير صالح | تحقق/أعد إنشاء المفتاح |
| `API_002` | حد المعدل | انتظر أو قم بالترقية |
| `API_003` | نقطة النهاية غير موجودة | تحقق من URL |
| `PAY_001` | الدفع مرفوض | تحقق من البطاقة/الحساب |
| `PAY_002` | الاشتراك منتهٍ | جدّد |
| `FILE_001` | الملف كبير جداً | قلل الحجم |
| `FILE_002` | التنسيق غير مدعوم | حوّل الملف |

## 8. التشخيص المتقدم

### 8.1 جمع معلومات التصحيح

افتح وحدة التحكم (F12) ونفذ:

```javascript
// انسخ هذه المعلومات للدعم
console.log({
  userAgent: navigator.userAgent,
  platform: navigator.platform,
  language: navigator.language,
  cookies: navigator.cookieEnabled,
  localStorage: typeof localStorage !== 'undefined',
  online: navigator.onLine,
  memory: navigator.deviceMemory,
});
```

### 8.2 تصدير السجلات

**في التطبيق:**
1. الإعدادات > متقدم > تصدير السجلات
2. ملف `iafactory-logs-YYYYMMDD.zip` يُحمّل

### 8.3 التحقق من الاتصال

```bash
# اختبار API
curl -I https://api.iafactory.ai/health

# اختبار WebSocket
wscat -c wss://ws.iafactory.ai/connect
```
