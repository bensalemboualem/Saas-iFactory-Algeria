## 1. Général

### Qu'est-ce qu'IAFACTORY ?

IAFACTORY est une plateforme d'intelligence artificielle qui vous permet d'interagir avec les modèles d'IA les plus avancés (GPT-4, Claude, Gemini, etc.) pour :
- Générer du texte, des images et du code
- Automatiser des tâches via des agents IA
- Analyser et transformer des documents
- Créer des workflows personnalisés

### Quels modèles d'IA sont disponibles ?

| Fournisseur | Modèles disponibles |
|-------------|---------------------|
| OpenAI | GPT-4o, GPT-4 Turbo, GPT-3.5 |
| Anthropic | Claude 3.5 Sonnet, Claude 3 Opus |
| Google | Gemini Pro, Gemini Ultra |
| Meta | Llama 3, Code Llama |
| Mistral | Mistral Large, Mixtral |

### Sur quelles plateformes IAFACTORY est-il disponible ?

- **Web** : app.iafactory.ai (tous navigateurs)
- **Desktop** : Windows, macOS, Linux
- **Mobile** : iOS et Android (bientôt)
- **API** : Intégration dans vos applications

## 2. Compte et inscription

### Comment créer un compte ?

1. Rendez-vous sur [app.iafactory.ai](https://app.iafactory.ai)
2. Cliquez sur "S'inscrire"
3. Entrez votre email ou utilisez Google/GitHub
4. Confirmez votre email
5. C'est prêt !

### Puis-je utiliser IAFACTORY sans compte ?

Non, un compte est nécessaire pour :
- Sauvegarder vos conversations
- Gérer vos crédits
- Accéder à toutes les fonctionnalités

### Comment supprimer mon compte ?

1. Allez dans **Paramètres** > **Compte**
2. Cliquez sur "Supprimer mon compte"
3. Confirmez par email

⚠️ Cette action est irréversible. Toutes vos données seront supprimées sous 30 jours.

### J'ai oublié mon mot de passe

1. Cliquez sur "Mot de passe oublié" sur la page de connexion
2. Entrez votre email
3. Cliquez sur le lien reçu par email
4. Définissez un nouveau mot de passe

## 4. Fonctionnalités

### Comment fonctionne le chat IA ?

1. Sélectionnez un modèle (GPT-4, Claude, etc.)
2. Tapez votre message ou question
3. L'IA génère une réponse
4. Continuez la conversation ou créez-en une nouvelle

### Puis-je uploader des fichiers ?

Oui, les formats supportés sont :
- **Documents** : PDF, Word, TXT, Markdown
- **Images** : PNG, JPG, WebP (pour analyse visuelle)
- **Code** : Tous les fichiers texte

**Limite** : 20 MB par fichier, 100 MB par conversation

### Qu'est-ce qu'un agent IA ?

Un agent est une IA autonome qui peut :
- Exécuter des tâches complexes en plusieurs étapes
- Utiliser des outils (recherche web, calcul, etc.)
- Interagir avec des APIs externes

**Exemples** : Agent de recherche, agent de coding, agent d'analyse de données

### Comment créer un workflow ?

1. Allez dans **Workflows** > **Nouveau**
2. Glissez-déposez les blocs d'actions
3. Connectez-les pour définir le flux
4. Testez et activez

Oui, des packs sont disponibles :
- 5 000 crédits : 500 DA
- 20 000 crédits : 1 800 DA
- 100 000 crédits : 8 000 DA

Les crédits supplémentaires n'expirent pas.

## 6. Confidentialité et sécurité

### Mes conversations sont-elles privées ?

Oui, absolument :
- Chiffrées en transit et au repos
- Non utilisées pour entraîner les modèles (sauf consentement)
- Non partagées avec des tiers

### IAFACTORY est-il conforme au RGPD ?

Oui, nous respectons :
- Le RGPD (Europe)
- La loi 18-07 (Algérie)
- Droit d'accès, rectification, suppression de vos données

### Où sont stockées mes données ?

- **Serveurs principaux** : Europe (France/Allemagne)
- **Backup** : Algérie

### Comment activer l'authentification à deux facteurs ?

1. **Paramètres** > **Sécurité**
2. Cliquez sur "Activer 2FA"
3. Scannez le QR code avec une app (Google Authenticator, Authy)
4. Entrez le code de vérification

## 7. Support technique

### Le chat ne fonctionne pas, que faire ?

1. **Vérifiez votre connexion** internet
2. **Rafraîchissez** la page (Ctrl+F5)
3. **Videz le cache** du navigateur
4. **Essayez** un autre navigateur
5. Si le problème persiste, contactez le support

### L'IA donne des réponses incorrectes

L'IA peut parfois :
- Donner des informations obsolètes (coupure de connaissance)
- "Halluciner" des informations fausses

**Conseils** :
- Vérifiez les faits importants
- Reformulez votre question avec plus de contexte
- Essayez un autre modèle

### Comment signaler un bug ?

1. Email : support@iafactory.ai
2. Dans l'app : **Aide** > **Signaler un bug**
3. Discord : canal #bugs

**Incluez** : capture d'écran, étapes pour reproduire, navigateur/OS

### Temps de réponse du support

|------|------------------|
| Gratuit | 5 jours ouvrés |
| Pro | 24 heures |
| Pro+ | 4 heures |
| Entreprise | 1 heure |
