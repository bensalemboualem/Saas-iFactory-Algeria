### حساب الأرصدة

```typescript
// services/credits/calculator.ts
export function calculateCredits(
  model: string,
  inputTokens: number,
  outputTokens: number
): number {
  const pricing = MODEL_PRICING[model];
  if (!pricing) throw new Error(`نموذج غير معروف: ${model}`);

  const inputCredits = (inputTokens / 1000) * pricing.inputRate;
  const outputCredits = (outputTokens / 1000) * pricing.outputRate;

  return Math.ceil(inputCredits + outputCredits);
}
```

## 4. طرق الدفع

### الجزائر - Chargily Pay

**الطرق المدعومة:**
- بطاقة CIB
- بطاقة الذهبية (EDAHABIA)
- التحويل البنكي

**كيفية الدفع:**
1. اختر باقتك
2. انقر على "الدفع بـ Chargily"
3. أدخل معلومات بطاقتك
4. أكد برمز OTP
5. يتم تفعيل الأرصدة فوراً

### الدفع الدولي - Stripe

**الطرق المدعومة:**
- Visa
- Mastercard
- American Express

**العملات المدعومة:**
- الدولار الأمريكي (USD)
- اليورو (EUR)
- الجنيه الإسترليني (GBP)

## 6. إدارة الاشتراكات

### إجراءات المستخدم

| الإجراء | الوصف |
|---------|-------|
| الترقية | الانتقال إلى باقة أعلى (فوري، مع حساب النسبة) |
| التخفيض | الانتقال إلى باقة أدنى (نهاية الفترة الحالية) |
| الإلغاء | إلغاء الاشتراك (الوصول حتى نهاية الفترة) |
| إعادة التفعيل | إعادة تفعيل بعد الإلغاء |

### سياسات الاسترداد

| الحالة | السياسة |
|--------|---------|
| الاشتراك السنوي | استرداد نسبي خلال 14 يوماً |
| الاشتراك الشهري | لا استرداد، إلغاء مجاني |
| الأرصدة الإضافية | غير قابلة للاسترداد بعد الاستخدام |

### مخطط قاعدة البيانات

```prisma
model User {
  id              String        @id @default(cuid())
  credits         Int           @default(100)
  creditsResetAt  DateTime?
  subscription    Subscription?
  invoices        Invoice[]
  creditHistory   CreditHistory[]
}

model Subscription {
  id                 String   @id @default(cuid())
  userId             String   @unique
  user               User     @relation(fields: [userId], references: [id])
  planId             String
  status             SubscriptionStatus
  currentPeriodStart DateTime
  currentPeriodEnd   DateTime
  cancelAtPeriodEnd  Boolean  @default(false)
}

model Invoice {
  id          String   @id @default(cuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id])
  amount      Int
  currency    String
  status      InvoiceStatus
  pdfUrl      String?
}

model CreditHistory {
  id          String   @id @default(cuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id])
  amount      Int      // موجب = مضاف، سالب = مستهلك
  reason      String
  metadata    Json?
}
```
