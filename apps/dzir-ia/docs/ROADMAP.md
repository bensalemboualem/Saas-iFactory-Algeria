# Dzir IA - Roadmap (2026-01-30)

## Vision
Construire un “Second Brain” type Remio.ai, mais **mieux**:
- Local-first + BYOK
- FR/AR/DZ friendly
- UX claire: capture → organise → ask → timeline

---

## Phase 0 — Stabilisation (Semaine 1)
- UI Home (dashboard clair)
- Page onboarding (connecter les sources)
- Routes Ask / Sources / Search / Timeline
- Corriger setup local (env, ports, build)

## Phase 1 — MVP Remio-like (Semaines 2–3)
- Landing marketing (clone Remio)
- Capture manuelle (URL / PDF / text)
- Ask avec citations (backend déjà présent)
- Collections enrichies (tags, source type)
- Timeline exploitable

## Phase 2 — “Better than Remio” (Semaines 4–6)
- Auto-capture (browser / desktop)
- Suggestions contextuelles (AI learns you)
- Multi-langue FR/AR
- Knowledge quality scoring
- Offline-first + sync fiable

## Phase 3 — Scale & Business (Semaines 7+)
- Desktop app (Tauri/Electron)
- Team spaces
- Billing (free/pro/BYOK)
- Analytics & monitoring

---

## Dépendances clés
- Qdrant + MinIO + SQLite OK
- BYOK / LLM provider (Gateway ou direct)
- UX remaniée (frontend)
